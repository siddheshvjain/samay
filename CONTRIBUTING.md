# Contributing to samay

Thanks for your interest in samay! This document covers how to set up your environment, contribute code, and submit strategies.

## Setup

```bash
git clone https://github.com/yourusername/samay.git
cd samay
pip install -e ".[dev]"
```

Set your environment variables:
```bash
cp .env.example .env
# Edit .env with your API keys
```

## Development

Run tests:
```bash
pytest tests/ -v
```

Lint your code:
```bash
ruff check samay/
```

## Contributing a Strategy

Strategies are the core of samay. They live in the `strategies/` directory.

### Format

Create a directory: `strategies/{category}/{strategy-name}/`

Inside, add three files:

**strategy.py** — A valid Python file with a Strategy subclass:
```python
from samay.strategy.base import Strategy
import pandas as pd

class MyStrategy(Strategy):
    name = "my-strategy"
    description = "Description of the strategy"
    author = "your_github_username"
    version = "1.0.0"
    
    def generate_signals(self, data: pd.DataFrame) -> pd.Series:
        # data has columns: open, high, low, close, volume
        # Return pd.Series of 1 (buy), -1 (sell), 0 (hold)
        signals = pd.Series(0, index=data.index)
        # ... implement your logic ...
        return signals
```

**metadata.json** — Strategy metadata:
```json
{
  "name": "my-strategy",
  "description": "Strategy description",
  "author": "your_github_username",
  "version": "1.0.0",
  "asset_class": "equity",
  "region": "us",
  "tickers": ["SPY", "QQQ"],
  "backtest_from": "2018-01-01",
  "backtest_to": "2024-01-01",
  "tags": ["momentum", "weekly"],
  "contributed_date": "2025-01-01"
}
```

**results.json** — AUTO-GENERATED BY CI. Do not hand-write this file.

### Submit

1. Fork the repo
2. Create a feature branch: `git checkout -b add-my-strategy`
3. Add your strategy in `strategies/{category}/{name}/`
4. Run: `samay publish path/to/strategy.py --name your-strategy-name`
5. Commit and push
6. Open a PR

GitHub Actions will auto-verify your strategy and post results as a comment.

## Adding a Broker Adapter

To add support for a new broker (e.g., Upstox, Binance):

1. Subclass `samay.brokers.base.BrokerAdapter`
2. Implement: `get_account()`, `get_positions()`, `place_order()`, `get_orders()`, `is_paper()`
3. Add environment variable handling in `__init__`
4. Add example usage in docstring
5. Submit PR

Example (Upstox):
```python
# samay/brokers/upstox.py
from samay.brokers.base import BrokerAdapter
import os

class UpstoxAdapter(BrokerAdapter):
    def __init__(self):
        api_key = os.getenv("UPSTOX_API_KEY")
        # ... init upstox client ...
    
    def get_account(self) -> dict:
        # ... implement ...
        pass
    
    # ... other methods ...
```

## Contributing a Skill

Skills are mental models about markets. They live in `skills/{topic}/SKILL.md`.

```markdown
---
name: my-topic
description: What this skill teaches
tags: [tag1, tag2]
contributed_by: your_github_username
---

# My Topic Skill

## Key Concepts
Explain the idea...

## When It Works
Conditions for success...

## When It Fails
Failure modes...

## Empirical Evidence
Link to backtests, lessons...
```

## Contributing a Lesson

Lessons share empirical discoveries. They live in `lessons/{region}/your-discovery.md`.

```markdown
---
title: Your Discovery Title
author: your_github_username
date: 2025-01-01
region: us
asset_class: equity
tags: [tag1, tag2]
---

## Hypothesis
What you're testing...

## Evidence
Backtest results showing the effect...

## Conclusion
What you learned...
```

## Graveyard

Document failed strategies honestly. They live in `graveyard/{name}.md`.

```markdown
---
title: Strategy That Failed
author: your_github_username
date: 2025-01-01
cause_of_death: "Broke after bear market"
---

## What It Was
Description...

## Why It Failed
Analysis...

## Lesson
What we learned...
```

## PR Guidelines

- Reference any related issues: "Fixes #123"
- Keep commits atomic
- Write clear commit messages: "Add momentum strategy for Nifty 50"
- Label your PR: `strategy`, `skill`, `lesson`, `broker-adapter`, `bug`, `enhancement`
- Link to strategy results or validation

## Labels

- `bug` — Something is broken
- `enhancement` — Feature request or improvement
- `good first issue` — Great for newcomers
- `strategy` — New strategy contribution
- `skill` — New trading concept/skill
- `lesson` — Empirical discovery
- `broker-adapter` — Support for new broker
- `graveyard` — Honest failure documentation

## Good First Issues

Easy entry points for new contributors:

1. Add Upstox adapter (India) — label: `good first issue`, `broker-adapter`
2. Add Binance adapter (Crypto) — label: `good first issue`, `broker-adapter`
3. Add mean-reversion strategy example — label: `good first issue`, `strategy`
4. Add India-specific momentum skill — label: `good first issue`, `skill`

## Code of Conduct

- Be respectful
- No financial promises or guarantees
- Share knowledge openly
- Validate claims with backtests
- Document failures honestly

*Questions? Open an issue or reach out to the maintainers.*
